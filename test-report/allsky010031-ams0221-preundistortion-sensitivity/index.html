Recommendation

Gold markers show the app's default optmod 2 parameter value for each one-parameter sweep.

  • For allsky7/optmod 2, pixel pre-undistortion is mainly sensitive to focal scale, principal point, and the radial alpha parameter.
  • The three attitude angles are shown for completeness, but this pre-undistortion diagnostic does not use attitude; those plots should be flat.
  • Use the default optmod 2 vector as a plausible first flattening candidate, but keep the calibrated f1/f2 aspect and radial alpha in the search grid.
  • A common f1/f2 zoom sweep is useful because triangle ratios are partly scale-invariant while pixel-side gates still introduce scale dependence.

Processing Steps Per Point

Important: this is a sensitivity diagnostic, not a full blind lucky run. It intentionally removes most false detections before the sweep so that the plot isolates how the asterism matcher responds to pre-undistortion errors.

  1. Load the allsky7 PNG image and run the automatic star detector once with the detector options below.
  2. Project the Yale catalogue through the supplied calibrated optmod 2 optpar. This creates the reference catalogue positions for the test case.
  3. Build an oracle validation map by matching automatic detections to those saved-calibration catalogue positions within the case match radius.
  4. For every sweep point, keep only automatic detections that were oracle-validated in step 3. This means the sweep is not measuring false-positive rejection.
  5. Pre-undistort both the oracle-validated detections and the catalogue positions with the perturbed optmod 2 vector for that sweep point.
  6. Run identifyStarsByAsterisms on those pre-undistorted positions using the matcher options below.
  7. Score the returned matches against the oracle validation map as correct, incorrect, or unknown.

The plots can therefore look better than a real GUI run if the live star finder produces many false positives, misses the useful stars, or if the initial blind optpar is much worse than the tested perturbation grid.
